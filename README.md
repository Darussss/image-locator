# 局部图片定位工具 · Image Locator

[![Python](https://img.shields.io/badge/python-3.9%2B-blue.svg)](https://www.python.org/)
[![OpenCV](https://img.shields.io/badge/OpenCV-4.x-green.svg)](https://opencv.org/)
[![License](https://img.shields.io/badge/license-MIT-orange.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/platform-Windows-lightgrey.svg)](#)

给你的地图、图纸、海报、截图配一个"查找相似区域"的放大镜：**截一小块，程序自动在原图上找出它在哪儿，并给出坐标。**

适合的场景：拿着别人发来的一小块地图截图，想在大图里定位；核对设计稿局部有没有被改动；在一张长图里找到某个表单位置。

> 仓库不附带任何地图/图纸图片，`huaiyanggudao.jpg` 仅作为默认文件名，请自备图片。

## 特性

| 特性 | 说明 |
| --- | --- |
| 自动载入原图 | 启动即读取程序同目录（或当前目录）的 `huaiyanggudao.jpg`，找不到会提示，无需手动选文件 |
| 快捷键截图取模板 | 按 `Ctrl+Alt+A` 冻结屏幕框选，**松开后在选区内双击**即送入程序，Esc / 右键取消 |
| 多尺度匹配 | 屏幕显示时图片常被缩放，程序在 0.15×–1.25× 之间按指数步进搜索最佳缩放 |
| 小角度旋转 | 支撑 ±6° 内的轻微倾斜（照片翻拍、屏幕拍摄常见） |
| 多候选 + 自动去重 | 一次给出前 N 个候选，重叠结果按 IoU / 包含度抑制（NMS） |
| 误报抑制 | 纹理一致性校验 + 极小模板惩罚，压掉平坦区域和低缩放档的假阳性 |
| 基准坐标输出 | 结果按"图一"坐标系换算（左上 0,0，默认 X 0–400 / Y 0–445），范围可改 |
| 可保存标注图 | 全分辨率标注图导出，框上方带序号、相似度和坐标 |
| 后台线程 + 进度条 | 匹配不卡界面，可实时看进度 |
| 零外部服务 | 全部本地计算，不联网、不上传图片 |

## 快速开始

### 方式一：直接用打包版（推荐给普通用户）

1. 下载 Releases 里的 `局部图片定位工具_Win64.zip`；
2. **解压后整个文件夹一起使用**（`局部图片定位工具.exe` 与 `_internal\` 必须同级，不能只拷 exe）；
3. 把要查找的原图重命名为 `huaiyanggudao.jpg` 放在 exe 同目录；
4. 双击 `局部图片定位工具.exe`。目标电脑无需安装 Python。

### 方式二：从源码运行

```bash
git clone https://github.com/<your-name>/<repo>.git
cd <repo>
pip install -r requirements.txt
python image_locator.py
```

Windows 下也可以双击 `run.bat`（会自动检测并安装缺失依赖）。

## 使用流程

1. 打开程序，确认左上角显示「原图：huaiyanggudao.jpg（宽 × 高）」；
2. 在屏幕上把原图打开并放大到你想要的那块区域附近；
3. 按 **`Ctrl+Alt+A`** → 全屏变暗冻结 → 按住左键拖出矩形；
4. **松开鼠标后，在选区内双击**（或按 `Enter`）→ 截图自动送入程序并立即开始查找；
5. 等待进度条完成：原图上出现候选框，右侧列表给出相似度与坐标；
6. 点列表某一行可高亮该候选；「复制坐标」把结果复制到剪贴板；「保存标注图」导出全分辨率结果。

> 快捷键被占用（微信/QQ 的截图键常占用 `Ctrl+Alt+A`）时，程序会在状态栏提示，点面板上的「截图 Ctrl+Alt+A」按钮效果一致。

## 坐标体系

默认以"图一"为基准：**左上角 (0, 0)，x 向右到 400，y 向下到 445**。

换算方式（不是写死的常数，改范围即按比例重算）：

```
x_基准 = 像素x / 原图宽 × X上限
y_基准 = 像素y / 原图高 × Y上限
```

- 右侧「坐标范围 X / Y」可随时修改，改完标注与列表立即重算，无需重新匹配；
- 每个候选同时输出**中心点坐标**和**区域范围**（左上 → 右下）；
- 如果 400 / 445 只是估值，建议先用已知地标校准一次，再改成实测值。

## 参数说明

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 灵敏度（阈值） | `0.39` | 归一化相关系数下限，越低越容易检出、误报越多 |
| 搜索精度 | `精细` | `快速`（单一角度、少尺度）/ `标准`（±3°）/ `精细`（±6°、32 个尺度） |
| 候选数量 | `3` | 最多返回的候选个数（1–10） |
| 允许小幅旋转 | 开 | 关闭可明显加快「精细」模式 |
| 坐标范围 X / Y | `400 / 445` | 基准坐标系的右上角刻度 |

「精细」大约要跑 32 个尺度 × 7 个角度 ≈ 224 次匹配，大图（4000×3000 级）可能几十秒，属正常；先用「快速」确认能命中，再切「精细」出终值。

## 工作原理

1. **载入**：`PIL` 读原图（兼容中文路径与 EXIF 方向），转 `numpy`；
2. **匹配**：灰度化后对每个缩放/角度组合做 `cv2.matchTemplate`（`TM_CCOEFF_NORMED`；纯色模板回退 `TM_SQDIFF_NORMED`）；
3. **取样**：每组合取相关度图上阈值以上的前 3 个局部峰值；
4. **过滤**：纹理一致性校验（局部标准差与模板相差过大则丢弃）+ 极小模板惩罚；
5. **去重**：跨尺度按 IoU > 0.25 或包含度 > 0.65 抑制，保留前 N 个；
6. **标注**：按基准坐标换算后在原图上画框与标签。

对透视变形严重的照片翻拍，模板匹配会掉分——见[路线图](#路线图)里的特征匹配兜底。

## 打包成 exe

Windows 上一键打包（PyInstaller，产出 `dist\局部图片定位工具\` 文件夹版）：

```bat
build_exe.bat
```

或手动执行（cmd）：

```bat
pip install pyinstaller
python -m PyInstaller --noconfirm --clean --windowed --onedir --name 局部图片定位工具 --icon app.ico image_locator.py
```

- **推荐 `--onedir`**：启动快、兼容性好，分发给他人时打包成 zip；
- `--onefile` 可得到单文件 exe，但每次启动要自解压，体积大、易被杀软拦截，且部分环境（如 Wine）下启动失败；
- 图标可用任意 `.ico`（256×256 含多尺寸），脚本会自动带上。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示「未找到 huaiyanggudao.jpg」 | 把图片放到 exe（或脚本）同目录，点「重载原图」 |
| 按 `Ctrl+Alt+A` 没反应 | 被微信/QQ/其它截图工具占用；用面板按钮，或改 `HOTKEY_VK` / `HOTKEY_LABEL` |
| 相似度偏低、找不到 | 降低灵敏度到 0.3–0.45；选区换大一点；用「精细」；确认截图里没有别的 UI 遮挡 |
| 坐标和自己量对不上 | 用已知地标校准，把「坐标范围 X / Y」改成实测刻度 |
| 匹配很慢 | 大图先缩小原图；或关掉「允许小幅旋转」；先用「快速」调试 |
| 杀软/SmartScreen 拦截 | PyInstaller 程序常见误报，添加信任即可；也可以自己从源码打包 |
| 启动报错 | 同目录会生成 `image_locator_error.log`，提 Issue 时请附上 |
