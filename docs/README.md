# docs 目录

把 README 里引用的截图放在这里，文件名固定：

- `screenshot-main.png` —— 主界面（原图带候选框 + 右侧结果列表，最好能看到坐标）
- `screenshot-snip.png` —— Ctrl+Alt+A 框选浮层（暗化屏幕 + 选区 + 双击提示）
- `screenshot-result.png` —— 保存下来的标注图局部（标签形如 `#1 0.648 (120, 135)`）

README 的「界面预览」一节把这些占位说明替换成：

```markdown
![主界面](docs/screenshot-main.png)
![框选](docs/screenshot-snip.png)
![标注结果](docs/screenshot-result.png)
```

截图里不要出现他人隐私信息，示例图用自己的或合成的。
